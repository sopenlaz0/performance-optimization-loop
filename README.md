# performance-optimization-loop

An agent skill for slow apps and performance sprints: measure real user journeys, optimize verified bottlenecks, and keep proven gains.

## Layout

```
performance-optimization-loop/
  SKILL.md
```

## Install

Copy the `performance-optimization-loop/` folder into your agent's skills directory, so that the file ends up at `<skills-dir>/performance-optimization-loop/SKILL.md`.

## Source

It adapts the method in [How we made claude.ai 3x faster in two weeks](https://claude.dev/blog/how-we-made-claude-ai-faster/). The gains reported in that article are not targets or guarantees for your app.
